# Code of conduct

OwnDesk follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind and patient, assume good intent, criticise code rather than people, and leave
harassment, insults and personal attacks out of every issue, pull request and discussion here.

It applies wherever someone speaks for the project or takes part in it: issues, pull requests,
reviews, and discussions.

## Reporting

Report anything that breaks it privately, through the repository's
[private report form](https://github.com/im-fahad/OwnDesk/security/advisories/new), with "Conduct:" at
the start of the title. The maintainer reads every report, keeps the reporter's identity private,
and answers within a week. What follows a breach is the Covenant's own ladder: a correction, a
warning, a temporary ban, or a permanent one.
